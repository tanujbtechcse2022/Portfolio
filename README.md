# 🌐 Personal Portfolio Website

A modern and responsive portfolio website built to showcase my skills, projects, certificates, and experience as an aspiring Software Engineer.  
The website is designed using **HTML, CSS, and JavaScript**, with clean UI components and smooth user interactions.

---

## 🚀 Features
- Fully responsive and mobile-friendly layout  
- Interactive UI elements using JavaScript  
- Smooth scrolling and animations  
- Sections for Projects, Skills, Certificates, and Contact  
- Clean code structure for easy updates  
- Fast-loading and optimized for performance  

---

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript**
- **Git & GitHub** (for version control and deployment)
